Logo 骑跨边框按钮

取 assets/icon/logo_black.svg / logo_white.svg 的像素波形 Logo，像徽章一样负偏移向左突出、垂直居中并上下溢出按钮， 用 z-index 盖住左边框，形成「骑跨」在边框上的装饰；2px 金属细边框闭环包住整颗按钮， 强调色光晕让 Logo 与边框、背景彼此融合。填充色由 CSS 变量随 深色 / 浅色 主题切换， 按钮支持大 / 中 / 小三档尺寸与多种宽度。

尺寸与宽度适配

每档尺寸演示三种宽度：全宽（width:100%）、固定宽、随内容自适应。点击任意按钮可预览。

主题色变体

Logo 光晕与金属边框可切换品牌三色系；幽灵按钮为透明面板 + 同款描边，保留骑跨装饰。

骑跨边框解析

Logo 与金属细边框的构成拆解。

① ② ③
①
整体金属细边框

2px 半透明描边 + 内发光，闭环包住整颗按钮；深色主题取半透明白，浅色主题取深蓝。

②
Logo 骑跨在边框上

left: -Npx 负偏移向左突出、垂直居中并上下溢出按钮，z-index: 2 盖住边框。

③
光晕融合

drop-shadow 强调色光晕 + 白边微光，让 Logo 与边框、背景彼此渗透，文字左内边距避让。

图标资源（assets/icon/）

原型直接内联源图标矩形像素数据，上图即原文件；按钮内复用同一图案，仅填充色改为主题变量。

按钮内复用 #logo-glyph 符号：矩形像素数据与源文件一致，去掉写死的填充色， 改为 fill: var(--logo-fill)，深色主题取亮像素、浅色主题取深像素，一套图案两种主题自适应。
