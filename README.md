# 宝宝剑控制 App · monster-king-lightstick

> **让宝宝剑，一直陪着音乐一起亮。** ✨

一个由**谦友制作的非官方宝宝剑控制 App**。

因为不想让宝宝剑只能在小程序中闪烁几分钟，
所以做了这个小东西。

连接宝宝剑，打开音乐，
让它跟着节奏一起呼吸、闪烁、变换颜色。

> 「我好像在哪见过你」（听歌歌词刚好到这，那就写这个吧）

也许我们都见过那束光。

---

## ✨ 它能做什么？

### 💡 控制宝宝剑

连接宝宝剑后，可以直接控制灯光：

* 🌑 黑屏
* 💡 常亮
* 🌈 随机色
* ⚡ 快闪
* 👀 眨眼
* 🌬️ 呼吸
* 🎉 聚会
* 🌈 彩虹
* ⭐ 星空

还可以自己调颜色。

**色环 + Hex + 亮度**，
想让它是什么颜色，就是什么颜色。

---

### 🎵 让宝宝剑跟着音乐一起亮

这是这个 App 最想做的事情。

手机麦克风采集音乐后，由 Rust 实时分析：

**音量 → 频带 → 节拍 → 灯光**

让宝宝剑不再只是“亮着”，
而是真的**跟着音乐动起来**。

目前提供：

* 🎵 单色律动
* 🌈 七彩律动
* 🔥 强烈律动
* 🌙 柔和律动

还可以调整灵敏度。

听歌，KTV的时候，
它可以跟着现场的音乐一起闪。

---

## 📱 后台也能继续亮

官方小程序存在运行限制，
无法长时间在后台持续使用手机麦克风。

所以这个 App 专门解决了这个问题。

Android 前台服务负责保持音乐监听，
即使：

* 锁屏
* 切到后台
* 手机长时间播放音乐

也可以继续进行音乐律动。

> **灯可以休息，但音乐还没有结束。**

## 🌟 关于“宝宝剑”

本项目使用微信小程序中分析得到的通信协议，
实现宝宝剑的独立控制。

协议实现目前包含：

* BLE 通信
* 灯效控制
* 颜色与亮度
* 座位绑定
* 广播
* OTA
* 数据校验
* 加解密
* Ed25519 签名验证

协议层目前拥有 **61 个单元测试**。

详细协议说明：

👉 [`docs/protocol/PROTOCOL.md`](docs/protocol/PROTOCOL.md)


## 🏗 技术架构

项目采用：

**Flutter + Rust + flutter_rust_bridge**

```text
Flutter
  │
  │ flutter_rust_bridge
  ↓
Rust API
  │
  ├── Bluetooth
  ├── Lightstick
  ├── Audio
  └── Protocol
          │
          ↓
    wan_protocol
```

简单来说：

> Flutter 负责“怎么操作”
> Rust 负责“宝宝剑怎么工作”

UI 层不直接接触 BLE 和协议实现，
方便以后替换 Native / Mock 实现。
